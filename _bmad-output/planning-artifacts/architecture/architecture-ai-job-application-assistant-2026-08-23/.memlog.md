- (decision) AD paradigm: pipes-and-filters pipeline (parse -> validate -> generate -> export) inside a single-process modular monolith
- (decision) Chosen topology (of 4 compared): thin-client SPA + tiny BFF server, same origin. Parsing (pdfjs-dist, mammoth) and export (docx, pdf-lib) run client-side; server is a pure LLM proxy serving static build. Rejected: Next.js fullstack (overkill), fat server (more code, no MVP benefit), serverless fns (cold starts, lock-in)
- (decision) Stateless orchestration: CLIENT drives 3 sequential API calls (validate-file is local, validate-vacancy POST, generate POST); no server sessions, no job ids, no in-memory server state; client holds texts in memory between steps
- (decision) Anti-fabrication mechanism (defense in depth): (1) system prompt hard rules - facts only from resume text provided in same request, (2) structured output responseSchema, (3) Zod validation of shape, (4) one repair-retry on invalid output, (5) grounding: only resume+vacancy texts in context, nothing else
- (decision) LLM recommendation: Google Gemini Flash free tier (zero budget, responseSchema support) with model alias pinned via env; fallback candidate OpenAI GPT-5 nano if region/billing blocks Gemini - final pick = USER QUESTION
- (decision) Limits: file <=5MB + PDF/DOCX only (client-side magic-byte check), vacancy <=10k chars, LLM call timeout 90s with AbortController, one repair-retry per generation
- (decision) Security: API key only in server env (.env gitignored, platform secret store in prod); same-origin = no CORS needed, Vite dev proxy; server logs metadata only (durations, error types) never document content; no persistence anywhere
- (decision) Observability: JSON-line console logs on server (request id, stage, duration_ms, outcome), frontend ErrorBoundary + console; no APM for MVP
- (version) Verified Aug 2026: Node 24 LTS, Vite 7, React 19, pdfjs-dist 6.x (or unpdf), mammoth 1.12, docx 9.7, pdf-lib current, Gemini Flash free tier w/ responseSchema (~3% schema drift -> Zod+retry), GPT-5 nano $0.05/0.40 per MTok, Claude Haiku 4.5 $1/5 no free tier
