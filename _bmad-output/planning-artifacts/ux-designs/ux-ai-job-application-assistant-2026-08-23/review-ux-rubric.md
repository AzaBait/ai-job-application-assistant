# UX Rubric Review

Калибровка ставок: 2-дневный учебный MVP. Ожидания пропорциональные — проверяем полноту состояний, замкнутость IA, ясность взаимодействий и внутреннюю согласованность, не enterprise-планку.

## Вердикт: **pass-with-findings**

Спецификация зрелая для своих ставок: IA замкнута (все FR-1…FR-11 имеют поверхности), набор состояний почти полный, a11y-floor задан конкретно, адаптив покрыт. Находки — точечные, ни одна не блокирует переход к архитектуре/сторям.

| Критерий | Оценка |

## Находки

1. **[Medium] Не определено поведение при ошибке скачивания (FR-11).**
   Локация: EXPERIENCE.md, State Patterns / Component Patterns («Document card»).
   Все ошибки генерации и ввода покрыты, но скачивание PDF/DOCX может упасть — закрыто лишь `[OPTIONAL: toast]`, что противоречит собственному правилу «избегаем глобальных toast-ов».
   Фикс: одно предложение в State Patterns — inline-сообщение внутри карточки документа с кнопкой «Повторить скачивание». Три строки текста, состояние замкнёт.

2. **[Low] Расхождение синтаксиса токенов между документами.**
   Локация: EXPERIENCE.md:94 (`{color.text}`, `{color.text-muted}`) vs DESIGN.md Components (`{colors.accent}`, `{colors.border}` — множественное число).
   Фикс: привести к единому виду `{colors.*}` в EXPERIENCE.md (или наоборот), чтобы ссылки были механически разрешимы.

3. **[Low] Поведение textarea при превышении лимита не задано.**
   Локация: EXPERIENCE.md, Component Patterns («Textarea вакансии»). Счётчик есть, лимит 10 000 (FR-3) есть, но не сказано: блок ввода, обрезка или предупреждение после превышения.
   Фикс: одна строка — например «при превышении лимита счётчик краснеет ({colors.error}), кнопка остаётся заблокированной».

4. **[Low] Неоднозначен ли Stage tracker стадию загрузки файла.**
   Локация: EXPERIENCE.md, Component Patterns («Stage tracker») + State Patterns. FR-9 перечисляет «загрузка файла» как стадию, но в State Patterns она живёт в dropzone, а трекер показан только со стадии анализа.
   Фикс: одна фраза — «трекер появляется после успешного чтения файла; загрузка файла индицируется в dropzone» (или включить стадию в трекер).

5. **[Low] После успеха задан автоскролл, но не фокус.**
   Локация: EXPERIENCE.md, Interaction Primitives. Для клавиатуры и скринридеров скролла недостаточно — фокус должен переместиться на заголовок Зоны 3.
   Фикс: заменить «автоскролл к Зоне 3» на «автоскролл + перенос фокуса на заголовок Зоны 3 (`tabindex="-1"`)».

6. **[Info] Опечатки.**
   «Автосколл» (EXPERIENCE.md:99 → «Автоскролл»); «однoколоночный» (EXPERIENCE.md:103 — латинская «o» внутри русского слова, сломает поиск).

7. **[Info] Контраст disabled-кнопки.**
   Локация: DESIGN.md Components («Primary button»: фон `{colors.border}` + текст `{colors.text-muted}`). Disabled-элементы исключены из WCAG, но `#DEE2E6`+`#6C757D` визуально блёкло; проверить читаемость подсказки «чего не хватает» рядом. Не блокирует.

## Что сознательно не требует (калибровка ставок)

- Пустые состояния зон, skeleton-загрузки, error-boundary-страница — избыточны для одностраничного MVP.
- Полный tone-of-voice guide, i18n-механика — язык интерфейса уже корректно вынесен в открытый вопрос.
- Dark mode, PWA — корректно помечены `[FUTURE]`.
